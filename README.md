# Axel's Dreams

A native Android 2D platform game prototype made with Godot 4.

## Current prototype
- Landscape orientation and low-resolution retro presentation.
- First playable Axel placeholder: dark cat, amber eyes, red scarf and staff.
- Basic left/right movement and jump.
- On-screen touch controls for Android.
- Keyboard controls for testing in the Godot editor.

## Open the project
1. Install Godot 4.3 or a compatible Godot 4.x release.
2. Import this repository by selecting the folder containing `project.godot`.
3. Open `scenes/main.tscn` and press Play.

## Export to Android APK
Install the Android export templates for your Godot version, configure the Android SDK/JDK in Editor Settings, then add an Android export preset and export an APK. GitHub stores the project source; Godot generates the APK.
